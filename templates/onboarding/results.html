Connecting Your Client

Select your client below for configuration instructions.

  1. Open Claude (web at claude.ai, or the Claude Desktop app) and go to Settings.
  2. Click “Connectors” in the settings sidebar.
  3. Click “Add custom connector”.
  4. Name field: type a name, e.g. your company name.
  5. Remote MCP server URL field: paste the MCP Server URL:
    {{ mcp_server_url }}
  6. Click “Continue”.
  7. It may show “Couldn't determine the server settings” — this is expected, not an error. Click “Next”.
  8. Under “Authentication”, select “None”.
  9. Scroll to “Additional request headers” / “Request headers”, click “Add header”.
  10. In the header name dropdown, search for and select “x-api-key” (must pick from the list, typing a custom name won't work).
  11. In the Value field, paste the MCP API Key:
    {{ mcp_api_key }}
  12. Click “Add”.
  13. If it briefly shows “Connection issue”: start a brand new chat and check again — it usually shows “Connected” once a fresh chat is opened. If not, click the connector and press “Reconnect”.
  14. Start a new chat and try a tool, e.g. “list my buyers” or “show my dashboard summary”.

Steps may change as the provider updates their product — verify before publishing.

  1. Open Cursor and click the gear icon (top right) to open Settings.
  2. In the left sidebar, click “Tools & Integrations” (or “MCP Tools”).
  3. Click “Add Custom MCP” (or “New MCP Server”) — this opens your mcp.json file (~/.cursor/mcp.json for global, or .cursor/mcp.json in your project).
  4. Add this configuration: 
    {
  "mcpServers": {
    "digital-invoice-web": {
      "url": "{{ mcp_server_url }}",
      "headers": {
        "x-api-key": "{{ mcp_api_key }}"
      }
    }
  }
}
  5. Save the file. Return to Tools & Integrations and confirm “digital-invoice-web” shows a green/connected status (click Refresh if not).
  6. In Agent/Composer mode, describe an invoicing task and Cursor will call the tools automatically.
