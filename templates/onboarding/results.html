Connecting Your Client

Select your client below for configuration instructions.

  1. Open Claude (web or desktop) → Settings → Connectors.
  2. Click Add custom connector.
  3. Paste the MCP Server URL (shown above) into the URL field.
  4. If prompted for authentication, enter the MCP API Key shown above (or provide it as a Bearer token in the Authorization header).

Or configure manually in claude_desktop_config.json:

{
  "mcpServers": {
    "digital-invoice-web": {
      "url": "{{ mcp_server_url }}",
      "headers": {
        "Authorization": "Bearer {{ mcp_api_key }}"
      }
    }
  }
}
