Connect MCP to Your AI Client

Use your preferred LLM assistant (Claude, Claude Code, ChatGPT, Cursor, Antigravity) to automate Digital Invoicing Software workflows.

⚡
No API Key Needed:

This server uses OAuth 2.1 authentication. You do not need to copy or manage API keys. When you add this MCP server URL to your client, the client will prompt you to authenticate via Central Auth (the exact same account you used in Step 1). That step automatically issues the access token behind the scenes.

{{ mcp_server_url }}

For SSE transport clients that require an explicit stream endpoint, you can also use: {{ base_url }}/sse

Step-by-Step Setup Guides

Choose your AI platform below for tailored setup instructions.

  1. Open Settings: In the Claude desktop app or web interface, click on your profile/account icon in the bottom-left corner and select Settings.
  2. Navigate to Connectors: Select the Connectors (or Developer / MCP) tab from the left sidebar.
  3. Add Custom Connector: Click the Add custom connector button.
  4. Paste the MCP URL: In the URL field, paste the MCP Server Endpoint:
    {{ mcp_server_url }}
  5. Click Connect: Claude will verify the server and initiate the OAuth handshake.
  6. Authenticate with Central Auth: A browser window will open prompting you to log in with your Central Auth account. Approve access.
  7. Done! The connector now appears in your sidebar or prompt tools menu. You can ask Claude: "Check my digital invoicing portal login status" or "Show me failed invoices".

  1. Run the Setup Command: Open your terminal and run the following command to register the server:
    claude mcp add --transport http digital-invoice-web {{ mcp_server_url }}
  2. Browser Login: On first use, Claude Code will automatically launch a browser window to complete the Central Auth OAuth login.
  3. Approve Access: Click Authorize in your browser. The token is securely stored by Claude Code for all subsequent tool invocations.
  4. Verify Connection: Run claude and prompt: "Use digital-invoice-web to inspect current dashboard metrics".
